# ระบบนับเงินในวงเล่น (Room Money Ledger) — **v3**

แอปนับเงินสำหรับวงเล่นไพ่กับเพื่อน มี **Admin ประจำห้อง** ทำหน้าที่เป็นนายธนาคาร
ใช้กติกาเดิมพันแบบโป๊กเกอร์ · บันทึกทุกธุรกรรมแบบบัญชีคู่ · เงินในระบบต้องตรงกับที่เบิกเสมอ

## ▶️ เริ่มใช้งาน

**ลองเล่นเลย:** ดับเบิลคลิก [`app.html`](app.html) — เปิดในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไร

**เล่นจริงกับเพื่อน:** ทำตาม [`DEPLOY.md`](DEPLOY.md) — ต่อ Supabase + ขึ้น Vercel ได้ลิงก์ส่งให้เพื่อน (ฟรี ~10 นาที)

| โหมด | ใช้ยังไง | เหมาะกับ |
|---|---|---|
| 💻 **เครื่องนี้** (ค่าเริ่มต้น) | ใช้ได้ทันที เปิดหลายแท็บ/หน้าต่างเล่นข้ามกันได้ | ลองเล่น · เทสต์ · เล่นบนเครื่องเดียว |
| ☁️ **ข้ามเครื่อง** | ใส่ค่า Supabase (ในไฟล์ตอน deploy หรือกรอกในหน้าแรก) | **เล่นจริง** ทุกคนถือมือถือของตัวเอง |

> ไฟล์ HTML เดียวซิงก์ข้ามเครื่องเองไม่ได้ ต้องมีตัวกลาง — จึงใช้ **Supabase Realtime** (Postgres + WebSocket)
> แอปเขียนแบบ **event-sourced** ทั้งสองโหมดใช้ logic ชุดเดียวกัน ไม่มีการแยกโค้ด
> ตาราง `pk_events` ตั้ง policy ให้ **insert/select ได้ แต่ update/delete ไม่ได้** — ตรงกับหลัก append-only ของ ledger

## กติกาหลัก

**เรื่องเงิน**

1. เงินมีที่มาเดียว — ออกจาก BANK ของห้องโดย Admin เท่านั้น
2. สมการต้องตรงตลอดเวลา: `Σ กระเป๋าทุกคน + กองกลาง = เงินที่เบิกจาก BANK สุทธิ` ถ้าไม่ตรงระบบล็อกห้องทันที
3. โอนเงินระหว่างผู้เล่นทำได้ทันที ไม่ต้องรอ Admin (เงินไม่ออกจากระบบ) · ขอยืมต้องให้เจ้าของเงินยินยอม
4. เติมเงินจาก BANK และการขอเข้าเล่น ต้องผ่าน Admin เสมอ
5. จ่ายกองกลางต้องพอดีเป๊ะ ปุ่มยืนยันกดไม่ได้จนกว่ายอดจะตรง
6. ผู้เล่นเห็นเฉพาะกระเป๋าตัวเอง · Admin เห็นทุกคน และลงเล่นเองได้

7. **โอนสิทธิ์ Admin ให้ผู้เล่นคนอื่นได้** (เฉพาะ Admin เจ้าของห้อง)

**เรื่องการเดิมพัน (โป๊กเกอร์)**

8. **หนึ่งมือมีหลายรอบลงเงิน** — *ลงเงินกองกลาง* → *รอบลงเงินที่ 1* → *ที่ 2* → … กองสะสมต่อเนื่อง
   พอทุกคนลงเท่ากันระบบเปิดรอบลงเงินใหม่ให้เอง (ปิดสวิตช์ได้) · หน้าจอแยกยอดให้เห็นว่ารอบไหนเท่าไหร่ รวมเท่าไหร่
9. **เริ่มเดิมพันที่ผู้ชนะรอบก่อน** (รอบแรกเริ่มที่คนตำแหน่งที่ 1)
10. ตัวเลขบนชิพคือ **ยอดรวมของรอบ** — ลงไว้ ฿20 กด ฿30 = จ่ายเพิ่มแค่ ฿10
11. ห้ามลงน้อยกว่ายอดล่าสุด · ลงเท่ากันได้สีเดียวกัน · ขึ้นเดิมพันได้สีใหม่
12. **ขึ้นเดิมพันแล้วทุกคนต้องกลับมาตัดสินใจใหม่** — ตามเพิ่ม / ขึ้นอีก / หมอบ
13. รอบจบเมื่อผู้เล่นที่ยังไม่หมอบ **ลงเท่ากันหมด** (หรือเหลือคนเดียว)
14. Admin ย้ายตำแหน่งผู้เล่นได้ · ทุกจอบอกเสมอว่า "ตาต่อไปคือใคร"
15. เปิด/ปิดการปิดรอบอัตโนมัติเมื่อครบตาได้
16. **Admin สั่งพักการเล่นของคนที่ไม่อยู่ได้** (เจ้าตัวพักเอง/กลับมาเองก็ได้) — ระบบข้ามตาให้ทันที
    (กลางมือ: ยังไม่ลงเงิน = พักรอบ · ลงไปแล้ว = ถือว่าหมอบ เงินอยู่ในกอง) และไม่จัดที่นั่งในรอบใหม่จนกว่าจะปลดพัก

## สิ่งที่ยังไม่รองรับ

- All-in / Side pot (คนเงินไม่พอตาม ต้องเติมเงินหรือหมอบ)
- หลาย betting round ต่อ 1 มือ (flop/turn/river) — ตอนนี้ 1 รอบ = 1 กอง
- ม็อกอัพจอเก่าใน `.dc.html` ยังเป็นกติกา v2 (ดูตาราง "ต้องทำต่อ" ในหัวข้อ 12 ของ `02-UI-DESIGN-SPEC.md`)
